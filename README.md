### 🛒 [BuySmart](https://buysmart-ai.vercel.app) — AI-Powered E-Commerce Intelligence Platform
*Full Stack AI Application with Advanced Search*

A **production-ready** price comparison and recommendation platform aggregating products from **Amazon, Flipkart, Myntra, Meesho** with intelligent natural language search.

**Key Features:**
- 🔍 **AI-Powered Smart Search** — Natural language intent parsing (category, budget, brand, purpose, features)
- 🤖 **Hybrid Recommendation Engine** — TF-IDF vectorization + multi-factor scoring (relevance, quality, user preference, popularity, specs, freshness)
- 💰 **Multi-Platform Price Comparison** — Real-time aggregation with platform trust scoring
- 📊 **User Dashboard** — Shopping history, wishlist with price tracking, personalized suggestions
- 🛡️ **Secure Authentication** — JWT token flow, BCrypt hashing, role-based access (User/Admin)
- 🔐 **Admin Panel** — User management, AI provider status monitoring, search analytics, scraping monitor
- 🧪 **Comprehensive Testing** — 70+ automated tests across all features

**Tech Stack:** React.js | Python 3.12 + Flask 3.1 | PostgreSQL | Scikit-Learn | Google Gemini API / OpenAI GPT | JWT

**AI Resilience:**
- Optional AI enhancement (system works fully without API keys)
- 15-minute cooldown on rate-limit failures
- Intelligent local fallback parser (regex-based intent extraction)
- 24-hour query caching

**Advanced Features:**
- TF-IDF semantic similarity for product matching
- Category isolation (hard constraints prevent cross-category results)
- Deduplication of products across platforms
- APScheduler for background job management
- Production-grade error handling and logging
